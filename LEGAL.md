# Void Client Legal & Compliance Notes

This repository ships as a launcher template with placeholders only.

## Required Before Publishing

- Confirm legal rights for all client/game assets you distribute.
- Replace placeholders with assets you own or can use legally.
- Keep any required attribution/license files for dependencies and media.
- Ensure your deployment complies with hosting platform rules and local laws.

## Recommended Release Checklist

- `assets/client/` contains only authorized distributable files.
- `assets/images/` contains only owned/licensed graphics.
- `site-config.js` links and server info are correct.
- `robots.txt` and `sitemap.xml` point to your real GitHub Pages URL.
- Changelog updated for the current release.
